# 《地球 Online》第四版：任务日志

## 核心创意

整部片子是一个玩家的**任务日志**：从上学到现在，一条条任务、通知、对话框。故事主要靠屏幕上的文字推进，参考 Google《Parisian Love》只用搜索框讲完一段人生。旁白是这个玩家的心里话，男声，口语，带点自嘲，不讲道理。

结尾是一个"回环"：最后揭晓，片中那支 AI 队伍接到的任务，就是做出观众正在看的这部片子。而主角一直找不到的"让自己忘了看时间的事"，就在做这部片子的那个晚上出现了。全片不说"着迷"这个词，只用一个时间戳让观众自己明白。

- 时长：约 90 秒
- 配音：男声，放松，约每秒 3.5 字
- 视觉：干净的游戏 HUD 界面，等宽字体，深色底；从规整的网格逐渐变成自由的地图
- 旁白约 280 字；屏幕上另有大量界面文字，不重复旁白

---

## 〇 载入（0:00–0:04）

黑屏，一个光标在闪。

屏幕：`地球 Online` 下面一行小字 `载入存档……`

音乐：一个很轻的长音垫底。

## 一 新手村（0:04–0:18）

屏幕：任务日志，条目一行一行打出来，严格对齐，踩着节拍落下。

```
[主线] 背完第三单元单词            ✓
[主线] 期中考试 年级前五十         ✓
[主线] 高考 倒计时 100 天
```

旁边飘着几行灰色小字，被系统自动归类为「娱乐」：`课间打球`、`被没收的小说`、`同桌传来的纸条`。

> 旁白：上学那会儿，这个游戏很简单。系统告诉你打哪个怪，打完就给分。其他的事，都叫娱乐。

## 二 任务栏空了（0:18–0:30）

屏幕：`高考 ✓` 然后跳出 `主线任务已完成`、`下一个任务：——`。网格散开，镜头往后拉，露出一张巨大的、被迷雾盖住的地图。任务输入框里只剩光标在闪。

音乐几乎全收，只剩一点底噪。

> 旁白：毕业那天，任务栏空了。没有提示，也没有下一关。我在原地站了挺久。

## 三 挣钱（0:30–0:45）

光标自己打出两个字：`挣钱`。回车。

音乐进入稳定的节拍。通知一条接一条弹出，跟着节拍：

```
工资已到账
季度目标 ✓
23:47  方案第 6 版
工资已到账
年终奖已到账
```

角落的余额数字一路往上滚。

> 旁白：后来我自己填了一个：挣钱。挺好，目标清楚，数字会涨。

通知继续弹，但一条比一条小、一条比一条灰。节拍还在，变得有点机械。

> 旁白：只是有一天我发现，到账的提示音响了，我已经不会抬头了。

## 四 别人的任务（0:45–1:02）

静默两秒。

镜头从"我"的地图拉出去，迷雾散开，露出很多别的玩家。每个光点旁边，用打字机效果浮出一张小卡片：

```
楼下面馆老板
当前任务：把汤熬好
备注：每天只卖到下午两点

前同事 · 在大理
当前任务：今天什么都不做

我妈
当前任务：阳台那盆茉莉，今年得开花
```

音乐换成更暖、更松的旋律。

> 旁白：我开始留意别人头顶的任务。有人的主线是一锅汤，有人是一盆花。他们看起来，都挺高兴的。

画面：回到"我"的地图，迷雾里闪起一个很小的暖色光点，旁边标着 `01:40`。下一秒跳到 `08:00 闹钟`，光点灭了。

> 旁白：我也想要那样一件事，能让我忘了看时间。说实话，还没找到。偶尔碰到一下，第二天就没了。

## 五 AI 队伍（1:02–1:15）

屏幕：一个对话框。"我"打字：`帮我把一个想法做出来`。回车。

画面一分为二，二变四，四变八，最后是二十个小窗口，每个窗口一张 Agent 卡片，各自滚动着工作的文字：`调研`、`写旁白`、`配乐`、`配音`、`画面`、`剪辑`……

音乐层次一层层叠起来。

> 旁白：后来，我有了一支 AI 队伍。我说一句，它们就去做。能不能做出来，不再是问题。问题变成了：我到底想做什么。

## 六 回环（1:15–1:30）

二十个窗口收拢成一条进度条：

```
任务：把这些零零碎碎的想法，做成一部短片
渲染中 ███████████░░  87%
```

进度条里出现一个很小的缩略图，正是这部片子的第一帧：闪着的光标，`地球 Online`。

> 旁白：所以我给它们派了第一个任务：把我这些零零碎碎的想法，做成一部片子。就是你现在看的这部。

停一拍。屏幕角落的时钟：`02:13`。

> 旁白：做它的那天晚上，到两点多我才发现，忘了看时间。

任务日志最后一次出现：

```
[主线] 挣钱                        进行中
[支线] 一件让我忘了看时间的事      已触发
```

淡出。末张字卡：**游戏进行中**

留 3 秒音乐，结束。

## 说明

- 面馆老板、在大理的前同事、妈妈的茉莉、两点多这些细节都是虚构的叙事素材，可以换成你真实的人和事，越真越好。
- 片中"二十个 AI 窗口"会如实对应这部片子的实际制作分工。
